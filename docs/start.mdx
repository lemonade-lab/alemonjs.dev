## 日常使用

- 安装并加载

```sh
npm create alemonjs@latest -y --bot
cd alemonb
yarn install
```

- 启动并连接

> login 参数指定连接平台，此处以qq-bot为例，不指定则仅运行

```sh
yarn app --login qq-bot
```

[点击了解如何连接平台](https://alemonjs.com/docs/environment)

[点击了解如何安装插件](https://alemonjs.com/docs/apps)

## 开发者

### 使用模板

- 获取模板

```sh
npm create alemonjs@latest -y
```

- 进入并加载

```sh
cd alemonjs
yarn install
```

- 启动

```sh
yarn dev
```

### 手动构建

- 创建启动文件

```js title="index.js"
import { start } from 'alemonjs'
start({
  input: 'lib/index.js' // 模块入口文件
})
```

- 模块入口文件编写逻辑

```js title="lib/index.js"
import {
  defineChildren,
  defineRouter,
  logger,
  useMessage,
  Format
} from 'alemonjs'

const response = () => {
  // 使用消息工具
  const [message] = useMessage()
  // 构造消息内容
  const format = Format.create().addText('hello word')
  // 发送消息
  message.send({ format })
}

export default defineChildren({
  // 注册内容
  register() {
    return {
      responseRouter: defineRouter([
        {
          regular: /^(\/|#)?hello$/,
          handler: () => response
        }
      ])
    }
  },
  // 当注册完成时
  onCreated() {
    logger.info('本地测试启动')
  }
})
```

- 启动

```sh
node index.js
```
