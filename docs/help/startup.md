# 启动排查

## 工作台打不开

1. 检查 `alx` 启动终端是否仍在运行，有没有启动错误。
2. 使用终端实际显示的地址与端口；如果修改了端口，不要继续访问默认地址。
3. 检查工作台健康与环境：

```bash
alx health
alx doctor
```

后台服务可使用 `alx status` 与 `alx logs` 检查。手动下载后提示命令不存在时，按 [安装](/docs/alemonx/getting-started/install) 从程序所在目录启动。

## 机器人项目启动失败

先确认操作的是目标项目，再查看依赖安装和启动输出中的第一处错误：

| 线索               | 下一步                                             |
| ------------------ | -------------------------------------------------- |
| 找不到依赖或运行时 | 核对项目 README 的环境要求并完成依赖安装           |
| 端口占用           | 检查已有进程与项目端口配置，避免重复启动           |
| 缺少配置或凭据     | 对照框架和相关插件的配置说明                       |
| 加载的仍是旧代码   | 核对启动入口是否指向编译产物，并执行项目的构建脚本 |

## 运行成功但没有回复

工作台健康、进程存活与消息收发是不同的检查。继续按 [消息排查](/docs/help/messages) 检查入站、路由和出站阶段。

相关文档：[运行与日志](/docs/alemonx/use/runtime/run-and-monitor)、[运行配置](/docs/alemonjsDocs/getting-started/config)。
