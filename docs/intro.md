# 文档导航

工作台用于创建和运行机器人项目；机器人文档介绍指令开发和平台接入。工作台命令行为 `alx`，机器人项目命令行为 `alemonc`。

## 从这里开始

| 任务                       | 文档                                                                                 | 内容                         |
| -------------------------- | ------------------------------------------------------------------------------------ | ---------------------------- |
| 安装工作台，把项目运行起来 | [快速上手](/docs/alemonx/getting-started/quick-start)                                | 创建项目、运行与日志         |
| 编写机器人指令             | [编写指令](/docs/alemonjsDocs/getting-started/quick-start)                           | 事件、路由与消息             |
| 连接聊天平台               | [连接平台](/docs/alemonjsDocs/getting-started/connect-platform)                      | 选择已有适配器并按其说明配置 |
| 扩展工作台或接入新平台     | [开发入口](/docs/extensions)                                                         | 按扩展对象选择开发文档       |
| 查命令或开发接口           | [工作台命令行](/docs/alemonx/reference/cli)、[开发概览](/docs/alemonjsDocs/overview) | 按能力查阅                   |
| 解决启动、连接或回复问题   | [常见问题](/docs/help/overview)                                                      | 按故障发生的阶段检查         |

## 工作台使用

[安装](/docs/alemonx/getting-started/install) → [快速上手](/docs/alemonx/getting-started/quick-start) → [创建与导入](/docs/alemonx/use/projects/create-or-import) → [运行与日志](/docs/alemonx/use/runtime/run-and-monitor)。

项目运行后，按需使用 [Agent 任务](/docs/alemonx/use/agent/collaboration) 和 [系统插件](/docs/alemonx/use/plugins)。开发工作台扩展请进入 [系统插件开发](/docs/alemonx/develop/system-plugins)。

## 机器人开发

[创建项目](/docs/alemonjsDocs/getting-started/install) → [编写指令](/docs/alemonjsDocs/getting-started/quick-start) → [连接平台](/docs/alemonjsDocs/getting-started/connect-platform)。

入门之后按需学习 [事件处理](/docs/alemonjsDocs/core/response)、[Hooks](/docs/alemonjsDocs/core/hook)、[接口路由](/docs/alemonjsDocs/http/route)、[定时任务](/docs/alemonjsDocs/advanced/schedule)。其他开发主题见 [开发概览](/docs/alemonjsDocs/overview)。

## 生态与更新

[生态资源](https://open.alemonjs.com)用于寻找平台、机器人插件、模块和系统插件；文档站负责说明如何使用和开发。第三方资源的安装条件与兼容版本以对应项目说明为准。

版本变化见 [更新日志](/blog)。遇到问题时先记录正在使用的工作台、框架和插件版本，再查阅 [常见问题](/docs/help/overview)。
