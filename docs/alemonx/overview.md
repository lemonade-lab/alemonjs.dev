# ALemonX

ALemonX 是 AlemonJS 机器人的本地工作台，命令行程序名为 `alx`。

用户请从 [如何安装](/docs/alemonx/getting-started/install) 开始，随后阅读 [工作站开始](/docs/alemonx/getting-started/quick-start)。

开发机器人或扩展，请使用 [系统插件开发](/docs/alemonx/develop/system-plugins)、[机器人应用页](/docs/alemonx/develop/webview)、[构建规范](/docs/alemonx/develop/build)，或在[参考](/docs/alemonx/reference/cli)中查阅接口约定。
