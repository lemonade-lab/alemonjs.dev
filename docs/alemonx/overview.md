# 工作台概览

工作台用于管理本地机器人项目，命令行程序名为 `alx`。

首次使用，从 [安装](/docs/alemonx/getting-started/install) 开始，随后阅读 [快速上手](/docs/alemonx/getting-started/quick-start)。

开发系统插件和机器人页面，请阅读 [系统插件开发](/docs/alemonx/develop/system-plugins)、[机器人应用页](/docs/alemonx/develop/webview)、[构建规范](/docs/alemonx/develop/build)，命令参数见[工作台命令行](/docs/alemonx/reference/cli)。

- 修改项目：[Agent 任务](/docs/alemonx/use/agent/collaboration)。
- 使用已有扩展：[系统插件](/docs/alemonx/use/plugins)。
