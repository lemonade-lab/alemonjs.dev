# 安装工作台

## 桌面版

从 [AlemonX 发布页](https://github.com/lemonade-lab/alemonx/releases)展开 **Assets**，选择文件名以 `alemonx-desktop-` 开头的桌面包。

| 系统                | 打开方式                                                                                             |
| ------------------- | ---------------------------------------------------------------------------------------------------- |
| macOS Apple Silicon | 下载 macOS ARM64 ZIP，解压后双击 **ALemonX Desktop.app**。                                           |
| Windows x64         | 运行桌面安装程序，或解压桌面 ZIP 后双击 **ALemonX Desktop.exe**。使用 ZIP 时保留同目录的 `alx.exe`。 |
| Linux x64 / ARM64   | 选对应架构的桌面版归档包，解压后运行 `./alemonx-desktop`。系统依赖见包内 README。                    |

看到桌面工作台窗口后，继续[图文快速上手](/docs/alemonx/getting-started/quick-start)。

## 脚本安装

脚本安装的是浏览器工作台命令 `alx`。安装后运行 `alx --host 127.0.0.1`，打开终端显示的地址。

### Windows（脚本安装）

在 PowerShell 执行：

```powershell
irm https://raw.githubusercontent.com/lemonade-lab/alemonx/main/scripts/install.ps1 | iex
```

### macOS、Linux 和 FreeBSD

```sh
curl -fsSL https://raw.githubusercontent.com/lemonade-lab/alemonx/main/scripts/install.sh | sh
```

## 手动安装

| 系统                            | 下载文件                        |
| ------------------------------- | ------------------------------- |
| Windows x64                     | `alx-windows-amd64.zip`         |
| Windows ARM64                   | `alx-windows-arm64.zip`         |
| Windows 32 位                   | `alx-windows-386.zip`           |
| macOS Apple Silicon             | `alx-darwin-arm64.zip`          |
| macOS Intel                     | `alx-darwin-amd64.zip`          |
| Linux x64                       | `alx-linux-amd64.zip`           |
| Linux ARM64                     | `alx-linux-arm64.zip`           |
| Linux ARMv7                     | `alx-linux-armv7.zip`           |
| Linux 32 位 x86                 | `alx-linux-386.zip`             |
| Linux ppc64le / s390x / riscv64 | 对应的 `alx-linux-<架构>.zip`   |
| FreeBSD x64 / ARM64             | 对应的 `alx-freebsd-<架构>.zip` |

从上方发布页选择对应的 ZIP 并解压。Windows 在 PowerShell 执行 `.\alx.exe --host 127.0.0.1`。macOS、Linux 或 FreeBSD 在终端执行：

```bash
chmod +x alx
./alx --host 127.0.0.1
```

如需下载代理，使用 `https://download.alemonjs.com/application/alemonx/<版本>/<包名>`。
