# 安装

## 脚本安装

### Windows（脚本安装）

在 PowerShell 执行：

```powershell
irm https://raw.githubusercontent.com/lemonade-lab/alemonx/main/scripts/install.ps1 | iex
```

### Linux

在终端执行：

```sh
curl -fsSL https://raw.githubusercontent.com/lemonade-lab/alemonx/main/scripts/install.sh | sh
```

### macOS

在终端执行：

```sh
curl -fsSL https://raw.githubusercontent.com/lemonade-lab/alemonx/main/scripts/install.sh | sh
```

### FreeBSD

在终端执行：

```sh
curl -fsSL https://raw.githubusercontent.com/lemonade-lab/alemonx/main/scripts/install.sh | sh
```

## 手动安装

| 系统                            | 下载文件                        |
| ------------------------------- | ------------------------------- |
| Windows x64                     | `alx-windows-amd64.zip`         |
| Windows ARM64                   | `alx-windows-arm64.zip`         |
| Windows 32 位                   | `alx-windows-386.zip`           |
| macOS Apple Silicon             | `alx-darwin-arm64.zip`          |
| macOS Intel                     | `alx-darwin-amd64.zip`          |
| Linux x64                       | `alx-linux-amd64.zip`           |
| Linux ARM64                     | `alx-linux-arm64.zip`           |
| Linux ARMv7                     | `alx-linux-armv7.zip`           |
| Linux 32 位 x86                 | `alx-linux-386.zip`             |
| Linux ppc64le / s390x / riscv64 | 对应的 `alx-linux-<架构>.zip`   |
| FreeBSD x64 / ARM64             | 对应的 `alx-freebsd-<架构>.zip` |

如需手动下载，可从 [GitHub Releases](https://github.com/lemonade-lab/alemonx/releases) 选择对应系统的压缩包：

- GitHub 下载地址格式：https://github.com/lemonade-lab/alemonx/releases/download/{{版本}}/{{包名}}
- 例如：https://github.com/lemonade-lab/alemonx/releases/download/v0.2.19/alx-windows-amd64.zip

解压下载的 ZIP 文件，取得可执行文件。

如果你遇到网络问题，可尝试使用官网代理：

- 代理下载地址格式：https://download.alemonjs.com/application/alemonx/{{版本}}/{{包名}}
- 例如：https://download.alemonjs.com/application/alemonx/v0.2.19/alx-windows-amd64.zip

### Windows（手动安装）

> 需要管理员权限的操作，按系统提示授权。

Windows 直接运行 `alx.exe`。

### macOS / Linux / FreeBSD

为程序添加执行权限后启动：

```bash
chmod +x alx
./alx
```

## Docker

在用于部署工作台的目录中创建 `docker-compose.yml`：

```yml
services:
  alx:
    image: ${ALX_IMAGE:-ccr.ccs.tencentyun.com/ningmengchongshui/alemonx}
    container_name: ${ALX_CONTAINER_NAME:-alx}
    restart: unless-stopped
    ports:
      - '${ALX_PORT:-17390}:17390'
    environment:
      TZ: ${TZ:-Asia/Shanghai}
      HOME: /root
      XDG_CONFIG_HOME: /root/config
      XDG_CACHE_HOME: /root/cache
      ALX_DEPLOYMENT: ${ALX_DEPLOYMENT:-production}
      ALX_OPS_STORAGE: sqlite
      ALX_CONTAINER: '1'
      ALX_WORKSPACE: /app/workspace
      ALEMONJS_SETUP_ROOTS: /app/workspace
      ALX_PRIVILEGED_MODE: ${ALX_PRIVILEGED_MODE:-enabled}
      ALX_PLUGIN_GITHUB_API_MIRROR: ${ALX_PLUGIN_GITHUB_API_MIRROR:-}
      ALX_PLUGIN_DOWNLOAD_MIRRORS: ${ALX_PLUGIN_DOWNLOAD_MIRRORS:-}
      ALX_SNOWLUMA_ENABLED: ${ALX_SNOWLUMA_ENABLED:-0}
    volumes:
      - ./data:/root
      - ./workspace:/app/workspace
    shm_size: '1gb'
    healthcheck:
      test: ['CMD-SHELL', 'curl -fsS http://127.0.0.1:17390/healthz >/dev/null']
      interval: 30s
      timeout: 5s
      retries: 3
      start_period: 20s
```

在终端中执行：

```bash
docker compose up -d
```

启动后打开工作台地址，继续阅读[快速上手](/docs/alemonx/getting-started/quick-start)。
