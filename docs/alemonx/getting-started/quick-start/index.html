工作站开始

在浏览器打开终端显示的地址，默认是 http://127.0.0.1:17390。

引导安装

  • 如果你是想体验机器人，可安装源码版机器人
  • 如果你是一名开发者，可根据引导创建开发模板

创建或导入项目

  1. 选择“创建项目”，或导入本地目录、克隆 Git 仓库。
  2. 在项目页完成环境与依赖检查。
  3. 使用前台运行查看输出，或使用 PM2 启动后台进程。

创建任务

填写任务目标，阅读计划后批准写入操作。完成后打开任务报告查看验证输出。
