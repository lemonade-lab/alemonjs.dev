# 如何安装

:::info

`npm create alemonjs` 已停止维护，不再用于创建项目。

:::

## 使用 ALemonX

从 [ALemonX Releases](https://github.com/lemonade-lab/alemonx/releases) 下载对应系统的文件。Windows 直接双击；macOS 与 Linux 在下载目录中运行：

```bash
./alx install --port 17390
```

在浏览器打开终端显示的地址（默认 `http://localhost:17390`），创建项目并完成平台连接。

了解什么是 [ALemonX](https://github.com/lemonade-lab/alemonx)，请 [点击访问](https://github.com/lemonade-lab/alemonx)

## 手动构建

适合需要自行维护项目的开发者。

```bash
mkdir my-alemonjs-app
cd my-alemonjs-app
npm init -y
npm install alemonjs
```

在 `package.json` 中设置 `"type": "module"`，然后创建入口文件：

```js title="index.js"
import { start } from 'alemonjs'

start('src/index.js')
```

按[开发手册](/docs/alemonjsDocs/core/router-sdl)编写路由和响应，然后启动：

```bash
node index.js
```

接着按[连接平台](/docs/environment)配置机器人账号。
