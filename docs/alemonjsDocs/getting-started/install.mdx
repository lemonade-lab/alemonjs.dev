# 创建项目

## 使用工作台

完成[安装](/docs/alemonx/getting-started/install)后，按[创建与导入](/docs/alemonx/use/projects/create-or-import)选择开发模板。

## 使用脚手架

先安装 Node.js，再运行：

```bash
npm create alemonjs
cd alemonjs
```

## 手动创建

适合需要自行维护项目的开发者。

```bash
mkdir alemonb
cd alemonb
npm init -y
npm install alemonjs
```

在 `package.json` 中设置 `"type": "module"`，然后创建`index.js`入口文件：

```js title="index.js"
import { start } from 'alemonjs'
start()
```

下面的命令只启动框架，尚未注册机器人指令：

```bash
node index.js
```

需要完整指令示例时，使用开发模板并阅读[编写指令](/docs/alemonjsDocs/getting-started/quick-start)。随后按[连接平台](/docs/alemonjsDocs/getting-started/connect-platform)配置账号并验证回复。
