# 如何安装

:::info

`npm create alemonjs` 已停止维护，不再用于创建项目。

:::

## ALemonX 安装

[点击查看 如何安装 ALemonX](/docs/alemonx/getting-started/install)

## npm 安装

> 需要有nodejs环境

```bash
npm create alemonjs
cd alemonb
```

## 手动构建

适合需要自行维护项目的开发者。

```bash
mkdir alemonjs-app
cd alemonjs-app
npm init -y
npm install alemonjs
```

在 `package.json` 中设置 `"type": "module"`，然后创建`index.js`入口文件：

```js title="index.js"
import { start } from 'alemonjs'
start()
```

按[开发手册](/docs/alemonjsDocs/core/router-sdl)编写路由和响应，然后启动：

```bash
node index.js
```

接着按[连接平台](/docs/environment)配置机器人账号。
