# V2.0.0 正式发布

V2.0.0 于 2025 年 3 月 14 日正式发布。本页合并此前 rc.33 至 rc.94 的十篇预发布日志，并保留正式版新增的 JSX 消息示例。

以下接口名称和写法对应当时版本；当前用法见[开发概览](/docs/alemonjsDocs/overview)。

## 事件处理

- 支持文本、提及和公共消息创建事件，新增多个事件选择和非消息事件响应。
- 提供基于文件系统的匹配机制，增加 `regular` 正则匹配；未命中时继续后续处理。
- 增加中间件，并调整 `OnMiddleware` 写法，支持修改事件后通过 `next()` 继续处理。
- 支持响应分组，复用处理逻辑并共享后续流程控制。
- 提供观察者 Hook，新增 `useSubscribe`，分别订阅创建、中间件处理后和响应完成后的阶段。
- 新增 `next(true)` 等跨周期控制方式；订阅事件的数据结构改为链表。
- 新增 `useState`，控制响应和中间件的启用状态；通过 `eventState`、`unEventState` 订阅和取消订阅状态变化。

## 消息接口

- 支持发送文本和图片，新增 `Text style`、`Mention options` 与 `useMention` 提及解析。
- 图片来源扩展为网络地址和本地文件，分别使用 `ImageURL`、`ImageFile`。
- 新增 `sendToChannel`、`sendToUser`，向频道或用户主动发送消息。能否发送仍取决于平台限制。
- 新增 `createDataFormat`，统一组织待发送的消息内容。

## 配置与开发支持

- 增加配置管理器，支持配置热更新、启动参数和通过 `getConfig` 读取 `argv`。
- 增加 Redis 连接支持。
- 统一使用 tsx 环境，增加开发、打包和运行配置。
- 支持 CSS 预处理及非 JavaScript 模块导入。
- 提供自定义平台函数，并修复模块扩展问题。

## 接口变更

从早期预发布版本升级时，注意以下变化：

- 启动接口由 `onstart` 更名为 `start`。
- 用户头像地址改为异步获取：`await e.UserAvatar.toURL()`。
- 删除 `useParse` 和 `MessageBody`。

## JSX 消息

正式版新增 JSX 消息写法。以下为当时发布的示例：

```tsx
import React from 'react'
import { createSelects } from 'alemonjs'
import { Text, useSend } from 'alemonjs/jsx'
const selects = createSelects(['message.create'])
// 导出响应
export default onResponse(selects, event => {
  // 创建接口
  const Send = useSend(event)
  // 发送文本
  Send(<Text>hello</Text>)
})
```
