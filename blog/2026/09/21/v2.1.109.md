# 更新记录

本次更新根据 ALemonJS 仓库近期提交整理，覆盖核心包、官方平台包和 `alemonc` 工具链的新增内容。

## 核心接口

- Markdown 引用支持 Markdown 节点和节点数组，可表达多行、空段落和嵌套引用。
- 新增并扩展频道内容 Hook：`useSchedule`、`useForum`、`useAudio` 和 `useChannelSettings`。
- 新增菜单和命令面板 Hook：`useMenu`、`usePanel`。
- 统一 Action 上下文和 `ActionTarget`，支持从事件、群组、频道及私聊上下文解析目标。
- 扩展媒体上传、分片上传、主动发送和流式消息类型。
- `useMe`、`useGuild`、`useMember`、`useRole`、`usePermission`、`useReaction`、`useRequest` 等 Hook 补充更多查询和管理动作。

## QQ Bot

- 增加群聊和 C2C 非频道事件及框架动作。
- 支持命令面板、菜单、入群申请、申请策略、白名单和成员管理。
- 补充群禁言、黑名单、连接网关、媒体上传和流式消息能力。
- 拆分并整理 QQ Bot 的 API、事件、消息、框架和快速开始文档。

## 平台适配

- 新增微信个人号 iLink ClawBot 平台适配器。
- 扩展抖音桌面端和抖音机器人适配器，补充登录、网关、消息、媒体和联系人能力。
- Discord、KOOK、Bubble、Telegram、OneBot、Milky、Wechaty、企业微信等平台补充 Markdown 引用转换和降级处理。

## 工具链与运行时

- `alemonc` 增加分支和发布相关操作，并完善发布参数处理。
- CBP 运行时继续补充连接、登录和进程间通信能力。
- 平台适配器收到不支持的统一动作时，应返回明确结果，便于调用方判断能力范围。
