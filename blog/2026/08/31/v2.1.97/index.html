新增事件上下文

新增 createContext 和 configureContext，用于实现多轮对话、分步表单、验证码确认等有状态交互流程。

上下文支持：

  • 使用 scope 按用户、频道等维度隔离会话；
  • 使用 initialState 保存每个会话的状态；
  • 使用 expiresIn 设置过期时间；
  • 使用 conflict 处理同一作用域的重复会话；
  • 使用 action.close() 关闭上下文；
  • 使用 action.pass() 将当前事件继续交给普通路由。

详细说明请查看事件上下文。

事件上下文系统在 2.1.92 的开发历史中落地，后续 2.1.93 对 Context 类型、注册校验和依赖结构进行了整理。

新增 useConnection

查询当前机器人连接状态：

const [{ getStatus }] = useConnection()
const result = await getStatus({ BotId: 'bot-id' })

新增 useInteraction

确认按钮、命令等平台交互事件：

const [{ ack }] = useInteraction()
const result = await ack({
  InteractionId: 'interaction-id',
  code: 0
})

useMedia 能力扩展

媒体 Hook 现在支持 url、data、filePath、fileId 四种来源，并增加面向目标对象的 media.send()：

await media.send({
  target: { targetId: '123', scope: 'group' },
  type: 'image',
  url: 'https://example.com/image.png'
})

一次媒体操作只能提供一种媒体来源。

useMessage 发送失败提示

当适配器返回空结果，或返回结果中没有 ResultCode.Ok 时，框架会记录 WARN 日志。业务代码仍应通过返回结果的 code 判断发送是否成功。
