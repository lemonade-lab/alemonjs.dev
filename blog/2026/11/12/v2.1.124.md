# 更新记录

这次记录汇总了自 2.1.109 以来的主要变化。本次对应的 npm 稳定版本为 [alemonjs 2.1.124](https://www.npmjs.com/package/alemonjs/v/2.1.124) 和 [@alemonjs/qq-bot 2.1.46](https://www.npmjs.com/package/@alemonjs/qq-bot/v/2.1.46)。

## 应用运行与配置

- 可以在机器人运行时加载、重载或卸载已安装的应用包。热重载及卸载后重新挂载需要 Node.js 22.15 或更新版本和 ESM 应用包。[模块加载](/docs/alemonjsDocs/modules/models)
- `apps` 支持为各应用配置启用状态、加载顺序及指令前缀。`getAppConfig()` 和 `getAppConfigValue()` 按调用文件所属包读取应用配置。[运行配置](/docs/alemonjsDocs/getting-started/config) · [配置接口](/docs/alemonjsDocs/advanced/config)
- Expose 支持结构化输入和输出校验、授权与超时。`createBackgroundRunner()` 允许后台任务保留应用身份，并清除原聊天事件上下文。[Expose 插件能力](/docs/alemonjsDocs/advanced/expose)
- 应用启动先完成 CBP 传输握手，再运行应用初始化，修复进程就绪握手可能被初始化阻塞的问题。[启动排查](/docs/help/startup)
- 新增离线应用测试入口，框架内置提示支持中英文切换。`alemonc publish` 改为在临时工作树构建当前提交，并按目标产物分支命名决定是否创建标签。[应用离线测试](/docs/alemonjsDocs/advanced/testing) · [运行配置](/docs/alemonjsDocs/getting-started/config) · [机器人命令行](/docs/alemonjsDocs/getting-started/terminal-tools)

## 指令和消息

- `routeText.space` 控制前缀后是否需要空格。依赖 `/修仙 签到` 这类写法的应用，升级后需要显式配置 `space: true`。应用也可统一覆盖文本前缀，并按规则转换发出的指令按钮。[路由 DSL](/docs/alemonjsDocs/core/router-sdl)
- `Media.image()` 可用 URL、文件路径或 Base64 描述图片。QQ Bot 支持提前上传、查询和删除 Markdown 图片素材。[图片与平台素材](/docs/alemonjsDocs/advanced/media)

## QQ Bot

- 未映射的 QQ 推送可通过 `platform.raw` 接收，覆盖 WebSocket、签名 Webhook 和 Webhook 的 WebSocket 转发。[事件类型](/docs/alemonjsDocs/core/message-type)
- 修复扫码登录配置读取和 Markdown 内联指令按钮。群聊、频道的内联指令按钮将文字填入输入框，C2C 私聊支持自动发送。构造按钮时传入原始文本，适配器为输入型按钮处理 URL 编码。[QQ Bot 接入](/docs/alemonjsDocs/getting-started/qq-bot)
- 新增 `QQMarkdown` 专用格式工具，补齐群聊全体提及和频道及频道私信指令面板。[QQ Bot 接入](/docs/alemonjsDocs/getting-started/qq-bot)
